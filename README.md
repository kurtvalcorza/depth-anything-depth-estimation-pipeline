# Depth Anything V2 Small depth-estimation pipeline

DIMER inference wrapper for **Depth Anything V2 Small** (`depth-anything/Depth-Anything-V2-Small-hf`), pinned to an immutable Hugging Face revision and loaded only from a digest-verified local snapshot. The pipeline returns *relative inverse depth* at the input resolution; metric depth is out of scope.

## Upstream alignment

- Model: `depth-anything/Depth-Anything-V2-Small-hf`
- Revision: `5426e4f0f36572d16453bbda7a8389317b1bef99`
- Upstream weight license: Apache-2.0
- Upstream task: monocular relative depth estimation
- Repository adaptation: bounded supervised adaptation on `{id, image, depth, mask}` records (`adapt`) — the DPT neck and head on the frozen backbone (frozen policy) and an optional unfreeze of the last transformer blocks (unfrozen policy), selected against the untouched checkpoint (zero-shot policy) by validation AbsRel — measured by affine-aligned AbsRel and δ1 against metric depth (`evaluate`, `prior_baselines`); `predict` is unchanged and still emits relative inverse depth; the base weights are never redistributed and the adapter is a tutorial output

## Quick start

```python
from PIL import Image
from depth_anything_depth_estimation_pipeline import DepthAnythingPipeline, abs_rel

pipe = DepthAnythingPipeline.from_pretrained()          # verifies weights/depth-anything-v2-small first
result = pipe.predict(Image.open("photo.jpg"))
depth = result["depth"]                                  # float32 H x W, larger = nearer, relative scale
print(result["depth_kind"], depth.shape, result["depth_min"], result["depth_max"])

# optional: score against caller-supplied metric depth of the same shape
# error = abs_rel(depth, reference_depth_metres)

# adaptation: the pinned DIODE views (fetched and digest-checked at run time, 312 MB), priors, the policy ladder
from depth_anything_depth_estimation_pipeline import fetch_sample_dataset, prior_baselines

splits = fetch_sample_dataset()                                   # 24 / 8 / 8 {id, image, depth, mask} views, split by scan
print(prior_baselines(splits["test"])["vertical_gradient_prior"]["abs_rel"])
print(pipe.evaluate(splits["test"])["abs_rel"])                 # zero-shot policy
pipe.adapt(splits["train"], splits["validation"])                     # neck + head, then the last two blocks, selected on validation
print(pipe.adapter["policy"], pipe.evaluate(splits["test"])["abs_rel"])
pipe.save_artifact("outputs/depth_anything_adapter")             # adapter.safetensors + manifest.json
reloaded = DepthAnythingPipeline.from_artifact("outputs/depth_anything_adapter")
```

Install into a Python 3.12 environment that already holds the pinned dependencies with `pip install -e . --no-deps`; run `pytest -q -o addopts= tests` for the offline test suite (no weights needed; 2 model-backed tests run when the snapshot is staged).

## Weights layout

```
weights/depth-anything-v2-small/
  dimer-base-manifest.json   # modelId, revision, per-file bytes + SHA-256
  config.json
  preprocessor_config.json
  model.safetensors          # git-ignored, 99,173,660 bytes
  README.md
weights/diode-sample/        # git-ignored run-time cache of the 40 pinned DIODE views (312 MB)
```

`verify_snapshot()` checks every file against the manifest before `from_pretrained` loads anything; `allow_download=True` is the only way to fetch from the Hub, and it still pins `revision`.

## Input ceilings

`MIN_IMAGE_SIDE = 14`, `MAX_IMAGE_SIDE = 4096`, `MAX_ASPECT_RATIO = 4.0`; one image per call. See `MODEL_CARD.md` for the measured memory behind those numbers.

## Tutorial

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/kurtvalcorza/depth-anything-depth-estimation-pipeline/blob/main/tutorials/depth_anything_depth_estimation_colab.ipynb)

`tutorials/depth_anything_depth_estimation_colab.ipynb` is declared `E2E` (mode `GUIDED`) under DIMER Notebook Specification 2.0 and is **standalone** (§4): generated by `tools/build_notebook.py`, it carries the three pipeline modules (`pipeline.py`, `metrics.py`, `samples.py` — including the 40-view pinned DIODE table), the model identity, manifest digests and runtime pins, so the exported notebook runs without this repository (parity enforced by `tests/test_notebook_parity.py`; see `tutorials/README.md`). Its default path stages the missing `model.safetensors` with `stage_missing_files(..., allow_download=True)` and digest-verifies the snapshot, fetches the 40 digest-pinned DIODE views (RGB, metric depth, mask; 312 MB) and draws 24 / 8 / 8 views by a seeded split of whole scans with `validate_dataset`, `check_split_disjoint` and `scan_summary`, runs one test view through the inference contract with a `sample-sanity` `evaluation_report` against its metric reference, scores the untouched checkpoint on the test split beside a constant prior and a vertical-gradient prior (zero-shot AbsRel 0.180 against 0.335 and 0.260 in the recorded run), trains the DPT neck and head on the frozen backbone and then the last two transformer blocks with them and selects the ladder's best epoch by validation AbsRel with the checkpoint competing as epoch 0 (selected `unfrozen last 2 blocks + DPT neck and head`, 0.167 on the test split), renders depth maps before and after, and exports the trained tensors as a safetensors adapter that reloads to an identical depth map. Six `outputs/` artifacts are written. BYOD (a `.zip` with `records.csv` beside the image files and `.npy` arrays) is optional and gated off by default.
